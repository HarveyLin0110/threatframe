# Confluence-Ready Output Contract

Preferred full-report artifact:
`Product_Threat_Model_<Product>_<Version>.html`

Core sections:
1. Analysis Information
2. System Context / DFD
3. Assets & Attack Surface
4. Threat Analysis Register
5. Priority Threat Details
6. Risk Register
7. Treatment & Engineering Traceability
8. Defense-in-Depth Assessment
9. Open Issues / Evidence Needed
10. Review & Risk Acceptance
11. Optional Knowledge / Compliance Mappings
12. Traceability Summary

Threat Register stays compact. Threat Detail expands only priority threats. Risk Register contains only formally managed risks.

HTML uses semantic headings/tables and inline SVG, with no JavaScript or external assets. It must remain useful if Confluence strips styling.
