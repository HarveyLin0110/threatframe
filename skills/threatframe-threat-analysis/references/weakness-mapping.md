# CWE Weakness Mapping

Use `WM-xxx` for CWE mappings.

CWE describes software/hardware weakness types that can contribute to vulnerabilities.

Map CWE when:
- A weakness is observed.
- Design/code evidence supports it.
- A threat scenario explicitly assumes a plausible weakness and this is labeled as an assumption/inference.
- A vulnerability/root-cause analysis provides evidence.

Do not map CWE when:
- The threat is valid without a known weakness.
- The only goal is to make the threat table look complete.
- The exact weakness is unknown.

Record:
- WM ID
- Related T/SR/evidence
- CWE ID/name
- Mapping Status
- Root-cause rationale
- Source version
- Verified date
- Source/evidence

Use `Candidate Mapping` when current authoritative confirmation is unavailable.
